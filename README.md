# Keshav Srushti Oxygen Park Website Clone

A pixel-perfect, responsive static clone of [Keshav Srushti Oxygen Park](https://ksop.in/), celebrating tribes, nature conservation, and bamboo eco-tourism in Jawhar, Maharashtra.

## Features
- **100% Pixel-Perfect Design**: Matches the typography, colors, animations, and layouts of the live website.
- **Complete Multi-Page Structure**:
  - `Home`: Full hero section with high-resolution background video, highlights, and PM Mann Ki Baat showcase.
  - `About Us`: Living classroom overview, village development, and empowerment stories.
  - `Bamboo First`: Sustainable livelihoods, Project Green Gold, and artisan profiles.
  - `Packages`: Nature trails, school outings, and corporate retreat options.
  - `Shop`: Interactive catalog of authentic tribal bamboo handicrafts and lamps.
  - `Gallery`: Rich experiential journey photos and moments.
  - `Blog`: In-depth articles on sustainability, climate science, and rural empowerment.
  - `Visit & Booking`: Online entry reservation interface.
- **Media Included**: Original high-resolution photography, SVGs, and background video (`hero_video.mp4`).
- **Interactive UI**:
  - Full-screen mobile navigation drawer
  - Image lightbox modal for gallery exploration
  - Mute/Unmute video controls & smooth section scrolling
  - Category filters on Shop and Gallery
  - Direct WhatsApp booking integration

## Deployment
- Deployed on **Vercel** with custom routing and clean URLs (`vercel.json`).
- Source code hosted on **GitHub**.
